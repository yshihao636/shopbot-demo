## 文档基线与当前状态

两份 PRD 以 [90d40bfd](https://github.com/yshihao636/shopbot-demo/tree/90d40bfd9bab8c85ff81815140dfb0b22dd4bf92) 为历史业务基线，2026-10-31 修订为 v1.11，补健康必转、统计与预算口径。AI 版是规则唯一维护位置，人看版由其派生；旧工作区和旧需求包不覆盖当前规范。历史评测仍对应 v1.10，原始结果摘要和运行产物不回填。

产品仍按 v0.1–v0.5 分期，能力开放同时受产品版本与灰度阶段控制；生产接口、配置、值班与线上指标待核验。26 个页面仍待完整产品验收，逐页映射见 PRD 附录 E。

全 15 意图离线 P0 均值 92.67%，v3 首跑 95% 区间下限 90.1%；**v0.1 的 6 意图事后切片均值 86.67%，未达 90%**。三次运行重复同一批样本。模拟后端端到端成功率 96.43%（人工纠正 1 条误判，原始 95.24%）不能替代线上自动解决率或首版验收。

健康必转已在独立评测工程实现并做无模型调用的定向验证，尚未生产联调；不会回填为新的端到端成功率。凭证上传、业务工具超时 / 结果未知、多轮改主意三条完整路径仍未测，见[报告 6.5](ShopBot离线评测报告.md#65-公开未测清单)。完整单位成本和首响 ≤3s 未实测，PRD 7.2.1 仅给出预算与假设算例。原型运营数字仍为虚构演示值。
