## 文档基线与当前状态

两份 PRD 均以本仓库 `main` 的 [90d40bfd](https://github.com/yshihao636/shopbot-demo/tree/90d40bfd9bab8c85ff81815140dfb0b22dd4bf92) 为业务基线，2026-10-31 完成公开交付整理。AI 版是规则唯一维护位置，人看版由其派生；旧工作区和旧需求包不覆盖这份最终规范。

「最终版」指需求定义定稿。产品仍按 v0.1–v0.5 分期，能力开放同时受产品版本与灰度阶段控制；生产接口、配置、值班与线上指标待核验。

离线 P0 意图准确率为 92.67%；模拟后端端到端成功率为 96.43%（人工纠正 1 条误判，原始 95.24%）。二者均为本评测集结果，不能替代线上自动解决率。原型中的运营数字是演示值，具体证据和局限见评测报告。
