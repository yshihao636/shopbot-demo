# ShopBot 电商智能客服 Agent

ShopBot 是一个面向电商订单、物流和售后场景的可交互原型。用户可以通过对话查询进度、补全申请信息、提交售后申请，并在需要确认或人工介入时获得明确的下一步。

仓库包含客户端 12 个场景、管理端 14 个页面、产品方案、作品集和离线评测材料。页面中的订单、用户和运营数据均为虚构演示数据。

> 这是公开演示原型，不代表生产系统已经接通。生产接口、线上自动解决率、成本、首响和真实用户反馈仍需单独验证。

## 产品重点

- 以订单、物流、售后为一期主链路，覆盖查询、申请、确认、进度反馈和人工接管。
- 身份、订单归属、金额、规则和业务写入由工具与后端校验；Agent 不直接决定最终业务结果。
- 涉及退款、取消、凭证和其他高风险动作时，先补全必要信息，再展示结果并要求用户确认。
- 工具失败、超时、结果未知、数据冲突或健康风险出现时，不编造成功结果，转人工或保留可追踪的处理出口。
- 产品按 v0.1–v0.5 分期，能力同时受产品版本和灰度阶段控制。

## 本地预览

这是一个静态原型，无需构建工具。启动本地静态服务器即可预览：

```bash
git clone https://github.com/yshihao636/shopbot-demo.git
cd shopbot-demo
python -m http.server 8000
```

然后打开 <http://localhost:8000/>。

## 当前边界

- 生产订单、物流、售后、支付等接口尚未在本仓库中接通。
- 原型运营数字为演示值，不作为线上业务结果。
- 完整单位成本、首次响应时间、真实流量自动解决率、CSAT 和退款纠纷率尚未实测。
- 凭证上传、业务工具超时或结果未知、多轮改主意等完整路径仍有未测项，见评测报告中的公开未测清单。
